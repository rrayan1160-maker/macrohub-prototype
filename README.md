# MacroHub Flutter Prototype

Interactive Flutter prototype for a premium healthy meal subscription app.

## Run

```bash
flutter pub get
flutter run
```

The app uses mock data only and has no backend integration.

## Open Without Flutter

Open this file directly in any browser:

```text
web/index.html
```

This static version uses plain HTML, CSS, and JavaScript. It does not require Flutter, Dart, a backend, or a local server.
